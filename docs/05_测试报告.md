## 已知限制

- DHT11 精度有限，只适合作为基础环境监测。
- MQ2 需要预热，并且阈值需要根据现场环境调整。
- ESP8266 AT 指令链路在弱网环境下需要更完善的重连日志。
- Python 服务端是可选扩展，不是主链路必需组件。
