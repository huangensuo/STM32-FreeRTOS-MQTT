# 07 简历描述

## 简历一句话

基于 STM32F103C8T6、FreeRTOS、ESP8266 和 OneNET 设计智能环境监测与安全预警系统，实现多传感器采集、本地声光报警、MQTT 物模型上报和微信小程序远程控制。

## 简历项目描述

**STM32 智能环境监测与安全预警系统**

- 基于 STM32F103C8T6 和 FreeRTOS 设计多任务嵌入式系统，划分传感器采集、状态控制、OLED 显示、按键处理和 MQTT 通信任务。
- 集成 DHT11、MQ2、火焰传感器和 HC-SR312 人体红外模块，实现温湿度、烟雾、火焰和人体检测数据采集。
- 设计正常、预警、危险三级状态机，驱动 RGB、蜂鸣器、继电器风扇和 LED 完成本地报警与控制。
- 使用 ESP8266 通过 MQTT 接入 OneNET 物联网平台，实现设备属性上报和远程服务调用。
- 开发微信小程序和云函数代理，实现设备数据查看、远程控制和平台鉴权隔离。

## 项目难点

### 1. 多任务数据同步

系统存在传感器采集、显示、控制和通信多个任务。项目使用全局状态结构体和 FreeRTOS 互斥信号量保护共享数据，避免任务同时读写造成数据不一致。

### 2. MQ2 烟雾误报

MQ2 上电初期会漂移，固定阈值容易误报。项目设计了预热阶段、动态基准线和偏移量判断，提高了烟雾检测稳定性。

### 3. 本地控制和远程控制冲突

危险状态下本地安全逻辑优先，远程关闭类操作不能覆盖危险报警，避免误操作造成安全风险。

### 4. 云平台密钥保护

微信小程序前端不保存 OneNET Access Key，而是通过云函数代理访问平台接口，降低密钥泄露风险。

## 面试讲解顺序

1. 先讲项目目标：室内环境监测和安全预警。
2. 再讲硬件组成：STM32、ESP8266、DHT11、MQ2、火焰、人体红外和执行器。
3. 讲 FreeRTOS 任务划分。
4. 讲状态机和本地报警策略。
5. 讲 OneNET MQTT 上报和服务调用。
6. 讲微信小程序和云函数。
7. 最后讲优化点和不足。
