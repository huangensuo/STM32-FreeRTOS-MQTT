# 02 系统架构

## 总体架构

```text
传感器与执行器
  │
  ▼
STM32F103C8T6 + FreeRTOS
  │
  ▼
ESP8266 + MQTT
  │
  ▼
OneNET 物联网平台
  │
  ▼
微信云函数 onenetProxy
  │
  ▼
微信小程序
```

## STM32 固件架构

固件采用 FreeRTOS 多任务结构：

| 任务 | 作用 |
| --- | --- |
| TaskSensor | 采集温湿度、烟雾、火焰和人体红外数据 |
| TaskControl | 判断设备状态并控制执行器 |
| TaskDisplay | 刷新 OLED 显示 |
| TaskKey | 处理按键输入和阈值设置 |
| TaskMQTT | 管理 WiFi、MQTT、OneNET 上报和远程命令 |

## 数据流

```text
传感器
  ▼
TaskSensor
  ▼
g_SensorData
  ├─ TaskControl：状态判断
  ├─ TaskDisplay：本地显示
  └─ TaskMQTT：数据上报
```

## 控制流

```text
OneNET 服务调用
  ▼
ESP8266 + MQTT
  ▼
TaskMQTT
  ▼
CmdParser
  ▼
g_DeviceStatus
  ▼
TaskControl
  ▼
继电器 / 蜂鸣器 / LED / RGB
```

## 状态机

| 状态 | 编码 | 触发条件 | 执行动作 |
| --- | --- | --- | --- |
| 正常 | 0 | 温湿度正常，无火焰和烟雾 | 绿色指示，报警关闭 |
| 预警 | 1 | 温度或湿度超限，或烟雾达到预警偏移 | 蓝色提示，间歇报警，风扇开启 |
| 危险 | 2 | 火焰触发，或烟雾达到报警偏移 | 红色快闪，蜂鸣器报警，风扇开启 |

## 安全策略

- 设备断网时仍能本地检测和报警。
- 危险状态下本地报警优先，远程关闭类操作不能覆盖危险保护逻辑。
- 远程手动控制带有保持时间，避免长期覆盖自动状态机。
