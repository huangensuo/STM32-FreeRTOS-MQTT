# 01 项目总览

## 项目简介

本项目是一个基于 STM32F103C8T6 的智能环境监测与安全预警系统。设备端采集温湿度、烟雾、火焰和人体红外数据，根据传感器结果判断正常、预警、危险三种状态，并通过 RGB、蜂鸣器、继电器风扇和 LED 完成本地报警与控制。

设备通过 ESP8266 使用 MQTT 接入 OneNET 物联网平台，微信小程序通过云函数访问 OneNET，实现远程查看和控制。

## 项目目标

- 完成一个端、云、应用闭环的嵌入式物联网项目。
- 使用 FreeRTOS 管理多个实时任务。
- 实现环境监测、安全预警、本地报警和远程控制。
- 形成适合 GitHub 展示和简历说明的项目结构。

## 核心功能

- DHT11 温湿度采集。
- MQ2 烟雾 ADC 采集、预热、基准校准和去抖判断。
- 火焰传感器检测。
- HC-SR312 人体红外检测。
- OLED 本地显示。
- RGB、蜂鸣器、继电器、LED 控制。
- MQTT 接入 OneNET 物模型。
- 微信小程序查询数据和远程控制。
