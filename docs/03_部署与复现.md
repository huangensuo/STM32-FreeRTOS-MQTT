# 03 部署与复现

## 1. 准备环境

需要准备：

- Keil MDK
- STM32F103C8T6 开发板或自制板
- ESP8266 模块
- OneNET 账号
- 微信开发者工具
- 可选：Python 3.8+

## 2. 配置 STM32 固件

复制固件配置模板：

```text
Hardware/MQTT_Config_Template.h → Hardware/MQTT_Config.h
```

填写以下内容：

```c
#define WIFI_SSID      "your_wifi_ssid"
#define WIFI_PASSWORD  "your_wifi_password"
#define ONENET_PRODUCT_ID  "your_product_id"
#define ONENET_DEVICE_NAME "stm32_env_monitor"
#define MQTT_BROKER        "your_product_id.mqtts.acc.cmcconenet.cn"
#define MQTT_PASSWORD      "your_onenet_mqtt_token"
```

`Hardware/MQTT_Config.h` 是本地私有文件，不上传 GitHub。

## 3. 编译和烧录

使用 Keil 打开：

```text
Project.uvprojx
```

编译通过后烧录到 STM32。

## 4. 配置 OneNET

创建产品和设备，建议设备名：

```text
stm32_env_monitor
```

创建属性：

- `temp`
- `hum`
- `flame`
- `shock`
- `smoke_adc`
- `state`

创建服务：

- `relay`
- `buzzer`
- `led`
- `rgb`
- `get_status`
- `temp_threshold`
- `hum_threshold`

## 5. 部署微信小程序

使用微信开发者工具打开：

```text
微信小程序/
```

修改 `miniprogram/app.js` 中的云环境 ID：

```js
env: 'your_cloud_env_id'
```

部署云函数：

```text
微信小程序/cloudfunctions/onenetProxy
```

云函数环境变量：

```text
ONENET_ACCESS_KEY=your_onenet_access_key
ONENET_PRODUCT_ID=your_product_id
ONENET_DEVICE_NAME=stm32_env_monitor
ONENET_USER_ID=your_onenet_user_id
ONENET_BASE_URL=https://iot-api.heclouds.com
```

## 6. 可选服务器端

如果需要运行 Python 服务端：

```powershell
cd Server
pip install -r requirements.txt
python main.py
```

真实密钥写入 `.env`，不要提交 `.env`。
