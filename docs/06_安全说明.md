# 06 安全说明

## 不应提交到 GitHub 的内容

- WiFi 密码。
- OneNET MQTT Token。
- OneNET Access Key。
- OneNET 设备密钥。
- DeepSeek API Key。
- 微信云开发私有配置。
- `.env` 文件。
- `Hardware/MQTT_Config.h`。
- Keil 编译产物。
- 小程序 sourcemap。

## 推荐做法

### STM32 固件

公开提交：

```text
Hardware/MQTT_Config_Template.h
```

本地私有：

```text
Hardware/MQTT_Config.h
```

### 服务器和云函数

公开提交：

```text
.env.example
```

本地私有：

```text
.env
```

## 上传前检查命令

```powershell
git grep -n -I -E "PASSWORD|ACCESS_KEY|SECRET|TOKEN|WIFI|SSID|DEEPSEEK"
```

如果结果中出现真实密码或密钥，需要先删除或替换。

## 如果密钥已经泄露

1. 立即在 OneNET 控制台重新生成 Token 或密钥。
2. 修改本地配置和云函数环境变量。
3. 如果仓库已经公开，建议清理 Git 历史中的密钥记录。
4. 不要只删除当前文件，因为 Git 历史中仍可能保留泄露内容。
