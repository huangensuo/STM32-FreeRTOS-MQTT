# 04 通信协议

## MQTT 连接参数

| 参数 | 说明 |
| --- | --- |
| Broker | `{product_id}.mqtts.acc.cmcconenet.cn` |
| Port | 1883 |
| Client ID | `stm32_env_monitor` |
| Username | OneNET 产品 ID |
| Password | OneNET MQTT Token |

## 属性上报 Topic

```text
$sys/{product_id}/{device_name}/thing/property/post
```

## 属性上报示例

```json
{
  "id": "1",
  "version": "1.0",
  "params": {
    "temp": { "value": 28 },
    "hum": { "value": 60 },
    "flame": { "value": 0 },
    "shock": { "value": 0 },
    "smoke_adc": { "value": 1200 },
    "state": { "value": 0 }
  }
}
```

## 属性字段

| 字段 | 说明 |
| --- | --- |
| temp | 温度 |
| hum | 湿度 |
| flame | 火焰状态，0 无火焰，1 有火焰 |
| shock | 烟雾状态兼容字段，0 正常，1 异常 |
| smoke_adc | MQ2 原始 ADC 值 |
| state | 设备状态，0 正常，1 预警，2 危险 |

## 服务调用

服务调用 Topic：

```text
$sys/{product_id}/{device_name}/thing/service/{service}/invoke
```

支持服务：

| 服务 | 参数 | 说明 |
| --- | --- | --- |
| relay | value: 0/1 | 控制继电器 |
| buzzer | value: 0/1 | 控制蜂鸣器 |
| led | value: 0/1 | 控制 LED |
| rgb | value: 0/1/2/3 | 红、绿、蓝、关闭 |
| temp_threshold | value | 设置温度阈值 |
| hum_threshold | value | 设置湿度阈值 |

## 小程序云函数调用

查询属性：

```js
wx.cloud.callFunction({
  name: 'onenetProxy',
  data: { action: 'query' }
})
```

调用服务：

```js
wx.cloud.callFunction({
  name: 'onenetProxy',
  data: {
    action: 'command',
    identifier: 'relay',
    params: { value: 1 }
  }
})
```
